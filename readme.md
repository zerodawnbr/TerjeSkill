# 💀 Como Ganhar XP — CANNIBAL

Existem **4 formas exatas de ganhar XP** com as configurações atuais da árvore de habilidades **CANNIBAL**.

---

## 1. 🩸 Abater Sobreviventes

> **A maior fonte de XP.**

Sujar as mãos de sangue rende **50 XP por morte**. Porém, a engine possui algumas travas severas para impedir o *farm* de XP entre amigos.

### 🎯 Bônus de Headshot

Se a kill for realizada com um **tiro na cabeça**, a experiência recebe um multiplicador de **1.5x**.

- **XP normal:** `50 XP`
- **Headshot:** `50 × 1.5 = 75 XP`

### 📏 Distância Mínima

Pela variável:

`CannibalMinimumSurvivorDistance = 100`

o alvo precisa estar a **pelo menos 100 metros de distância** de você para que o XP seja contabilizado.

### ⏱️ Cooldown de Vítima

Você não pode matar a mesma pessoa repetidamente para acumular XP.

A variável:

`CannibalSameVictimExperienceCooldown = 3600`

exige que você espere **3600 segundos**, equivalente a:

**1 hora**

antes de ganhar XP novamente matando o mesmo jogador.

### ⏱️ Cooldown Geral

Existe também um intervalo de:

`60 segundos`

entre qualquer kill para que o XP seja validado.

---

## 2. 🔪 Esquartejar Cadáveres

> **Limpar a cena do crime também compensa.**

Esquartejar o cadáver de um jogador humano utilizando uma **faca** concede XP instantaneamente.

A quantidade de XP é definida pela variável:

`CannibalButcherCorpseExpGain`

- **XP por cadáver esquartejado:** `25 XP`

---

## 3. 🥩 Ingerir Carne Humana

> **O pão nosso de cada dia.**

Cada vez que o personagem ingere um **bife de carne humana processada**, ele recebe XP.

A quantidade de XP é definida pela variável:

`CannibalConsumeHumanFleshExpGain`

- **XP por pedaço consumido:** `10 XP`

---

## 4. 💀 Comer Diretamente do Cadáver

> **A barbárie extrema.**

Utilizar a ação de comer a carne **crua diretamente do cadáver no chão** concede XP adicional por mordida.

A quantidade de XP é definida pela variável:

`CannibalEatCorpseExpGain`

- **XP por mordida:** `5 XP`

---

# 🏆 Estratégia Mais Rápida

A forma mais rápida de evoluir essa árvore é combinar todas as fontes de XP:

1. 🎯 **Caçar jogadores a longa distância**
2. 🔫 **Garantir o Headshot** → `75 XP`
3. 🔪 **Ir até o corpo e esquartejá-lo** → `25 XP`
4. 🥩 **Consumir a carne gerada** → `10 XP por pedaço`
5. 💀 **Comer diretamente do cadáver** → `5 XP por mordida`

---

## 🛡️ Proteção Contra Abusos

O sistema possui mecanismos específicos para evitar o *farm* artificial de XP entre amigos:

- 📏 **Distância mínima:** `100 metros`
- ⏱️ **Cooldown da mesma vítima:** `3600 segundos`
- ⏱️ **Cooldown geral entre kills:** `60 segundos`
- 🎯 **Headshot:** multiplicador de `1.5x`

Essas restrições dificultam significativamente o uso de mortes combinadas entre jogadores para acelerar artificialmente a progressão.
